# career_matcher_ai — DeepSeek 决策版岗位匹配

## 概述

`career_matcher_ai.py` 采用**两阶段匹配**策略：先用关键词粗筛将 5 万条岗位缩小到 30 条候选，再将用户画像和候选岗位一起提交给 DeepSeek 大模型，由 LLM 分析语义匹配度并生成带理由的推荐报告。

对比纯关键词方案，DeepSeek 能理解：
- 用户情感状态（如"沮丧"、"面试失败"）对职业方向的影响
- 岗位职责描述中隐含的职业发展路径
- 学历/经验要求的弹性空间
- 跨领域的技能迁移可能性

## 适用场景

- 用户画像包含丰富的情感、事件、目标等非结构化信息
- 需要可解释的推荐理由（不只是"得分高"）
- 需要结合多维度信息做综合判断
- 有 DeepSeek API 可用

## 两阶段流程

```
┌───────────────────────────────────────────────────┐
│ Phase 1: 关键词粗筛 (~15s)                        │
│                                                    │
│  chat_memory.json → 提取关键词 → 扩展映射          │
│  岗位匹配数据.xlsx (50,000) → 逐条打分 → Top-30   │
│                                                    │
│  输出: 30 条候选岗位                               │
└────────────────┬──────────────────────────────────┘
                 │
                 ▼
┌───────────────────────────────────────────────────┐
│ Phase 2: DeepSeek 决策 (~10s API)                  │
│                                                    │
│  用户画像文本 + 候选岗位文本 → Prompt              │
│       │                                            │
│       ▼                                            │
│  DeepSeek 分析:                                    │
│  - 专业背景 ↔ 知识/技术要求                        │
│  - 偏好目标 ↔ 行业/岗位方向                        │
│  - 学历经验 ↔ 岗位门槛                             │
│  - 情感事件 ↔ 工作环境适配                         │
│  - 薪资/城市合理性                                 │
│       │                                            │
│       ▼                                            │
│  推荐报告: Top-5 + 理由 + 顾虑 + 总结              │
└───────────────────────────────────────────────────┘
```

## 核心模块

### AICareerMatcher 类

| 方法 | 说明 |
|---|---|
| `load_data(api_key, base_url)` | 加载数据，初始化 DeepSeek |
| `match(coarse_top_n=30, final_top_n=5)` | 两阶段匹配，返回推荐报告文本 |

### 独立函数

```python
from career_matcher_ai import ai_match_career

# 一行调用
report = ai_match_career(
    excel_path="岗位匹配数据.xlsx",
    memory_path="chat_memory.json",
    coarse_n=30,   # 粗筛候选数
    final_n=5,     # 最终推荐数
)
print(report)
```

### 命令行

```bash
python career_matcher_ai.py
```

## Prompt 设计

送给 DeepSeek 的 system prompt 设定了 6 个分析维度：

1. 专业背景是否匹配岗位知识/技术要求
2. 偏好目标是否与行业方向一致
3. 学历经验可适当放宽 1-2 年
4. 情感状态和近期事件反映的工作节奏需求
5. 薪资合理性
6. 城市匹配度（无偏好则忽略）

## 输出格式

每次推荐包含以下字段：

```
### 推荐 1: 软件测试工程师
- **匹配度**: ★★★★☆
- **推荐理由**: 计算机专业背景完全对口，该岗位对测试方法论的
  要求可以通过短期学习补足……
- **潜在顾虑**: 需要3年经验，你目前可能经验不足
- **公司**: XX科技有限公司
- **城市**: 成都
- **薪资**: 8,000 ~ 10,000

### 推荐 2: ...
```

末尾附 2-3 句总结建议。

## Token 估算

| 阶段 | 数据量 | 估算 Token |
|---|---|---|
| 粗筛输入 | 5 万条岗位 | 仅在 pandas 中处理，不消耗 token |
| 粗筛输出 | 30 条候选 | - |
| Prompt 输入 | 用户画像 + 30 条格式化岗位 | ~6,000-8,000 |
| Prompt 输出 | 5 条推荐 + 理由 | ~1,500-2,500 |

DeepSeek 上下文窗口 64K token，远在安全范围内。

## 参数调优

| 参数 | 默认值 | 建议范围 | 影响 |
|---|---|---|---|
| `coarse_n` | 30 | 20-50 | 越大候选越多、token 越多、覆盖面越广 |
| `final_n` | 5 | 3-10 | 最终推荐数 |
| `temperature` | 0.3 | 0.1-0.5 | 越低推荐越稳定，越高更多样 |

## 与 career_matcher.py 对比

| | career_matcher | career_matcher_ai |
|---|---|---|
| 策略 | 关键词加权打分 | 关键词粗筛 + LLM 精排 |
| 输出 | DataFrame | 自然语言推荐报告 |
| 可解释性 | 得分来源不透明 | 每条推荐附带理由和顾虑 |
| 情感/事件分析 | 不支持 | 支持 |
| API 依赖 | 无 | 需要 DeepSeek API |
| 速度 | ~15s | ~25s |
| 成本 | 免费 | ~0.01 元/次 |
