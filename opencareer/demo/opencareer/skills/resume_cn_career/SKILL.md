# 中文简历生成与优化

面向真实投递场景的中文简历工作流，支持从零生成、按 JD 优化、评分诊断、PDF 导出。

## 核心能力

1. 简历生成：按人群分流生成可投递版本。
2. 简历优化：根据 JD 做关键词与证据重排。
3. ATS 检查：规避格式与关键词风险。
4. PDF 导出：生成可复制文本、中文不乱码的 PDF。

## 分流逻辑

### 1) 校招 / 应届生

适用：0-1 年经验，实习和项目是核心证据。

执行步骤：
1. 收集教育背景、实习、课程项目、竞赛/奖项。
2. 优先使用校招模板，突出技术栈、项目角色和结果。
3. 经历写法采用“动作 + 方法 + 结果”，无结果数据时给出可验证事实。
4. 控制 1 页，补齐求职意向与到岗时间。

### 2) 社招初级

适用：1-3 年经验，需要证明可独立交付。

执行步骤：
1. 聚焦近 1-2 段工作经历与关键项目。
2. 以岗位匹配度排序要点，弱化不相关经历。
3. 每段经历至少 2 条可量化成果。
4. 输出 1 页到 1.5 页。

### 3) 社招中高级

适用：3-8 年经验，要求业务影响与复杂问题解决能力。

执行步骤：
1. 拆解 JD 的“必须项”和“加分项”。
2. 将核心项目按业务价值排序，突出指标改善。
3. 写清技术决策、跨团队协作和复盘沉淀。
4. 输出 1.5-2 页。

### 4) 资深 / 管理岗

适用：8 年以上或带团队角色，要求战略与组织贡献。

执行步骤：
1. 强化团队规模、预算、组织效率与业务结果。
2. 增加“管理成果”与“影响半径”模块。
3. 用案例呈现“问题-决策-落地-结果”。
4. 输出 2 页内，保留关键证据，不堆砌术语。

### 5) 转行

适用：目标岗位与既有经历不完全一致。

执行步骤：
1. 提炼可迁移能力（如数据分析、项目管理、沟通协作）。
2. 用项目/实战证明新方向能力，不使用空泛自评。
3. 在摘要中解释转行动机与路径。
4. 对照 JD 进行关键词映射与补足。

### 6) 中英双语

适用：外企、跨境岗位或明确要求英文简历。

执行步骤：
1. 先完成中文主版，确保事实一致。
2. 再生成英文版，不做机器直译，保持语义与语气专业。
3. 中文与英文简历的指标、时间线、项目事实必须一致。
4. 输出文件建议：中文与英文分别导出 PDF。

## 统一流程

1. 信息收集：岗位方向、经验、项目、成果、技能、教育、证书。
2. 选择分流：按上述 6 类进入对应模板。
3. 内容生成：优先岗位匹配，遵循 [中文写作最佳实践](./references/best-practices.md)。
4. 质量评估：按 [中文简历自检与评分](./references/analysis-checklist.md) 评分并修正。
5. ATS 优化：按 [中文 ATS 优化指南](./references/ats-optimization.md) 调整关键词和格式。
6. PDF 导出：使用 [导出脚本](./scripts/generate_resume_pdf.py) 生成可投递 PDF。

## OpenCareer 集成说明

本 SKILL 已集成到 OpenCareer 架构中，支持以下操作：

```python
# 通过 SkillRegistry 执行
from opencareer.skills.skill_registry import get_global_registry

registry = get_global_registry()
result = await registry.execute("resume_cn_career", {
    "action": "generate",
    "name": "张三",
    "target_role": "软件工程师",
    "job_type": "校招",
    "education": "北京大学 / 计算机科学 / 本科 / 2024",
    "experiences": [
        "在字节跳动实习3个月，开发用户增长功能",
        "获得国家奖学金"
    ],
    "skills": ["Python", "Java", "机器学习"]
})
```

## 输出要求

1. 不编造经历、学历、证书与指标。
2. 主版本必须为中文，双语场景再补英文版本。
3. 版式保持 ATS 友好：单栏、标准标题、可复制文本。
4. 文件名清晰：姓名_岗位_年份.pdf。
