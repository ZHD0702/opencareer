OpenCareer 项目运行指南
============================

一、前提条件
-----------
1. Python 3.9+
2. Redis (用于任务调度)
3. Poetry (依赖管理，推荐)
4. DeepSeek API密钥 (从 https://platform.deepseek.com/ 获取)

二、快速开始 (完整系统)
---------------------
1. 安装依赖
   ```bash
   cd demo
   poetry install
   ```

2. 配置环境变量
   ```bash
   cp .env.example .env
   # 编辑.env文件，设置DeepSeek API密钥:
   # DEEPSEEK_API_KEY=your_key_here
   ```

3. 启动Redis
   ```bash
   docker run -p 6379:6379 redis:alpine
   ```

4. 运行系统
   ```bash
   # 启动MCP服务器 (新终端)
   poetry run python -m opencareer.mcp.server
   # 服务器运行在 http://localhost:8000

   # 运行演示 (新终端)
   poetry run python demo_main.py
   ```

三、简化运行 (仅聊天功能)
-----------------------
1. 安装最小依赖
   ```bash
   pip install aiohttp python-dotenv
   ```

2. 配置API密钥
   ```bash
   export DEEPSEEK_API_KEY=your_key_here
   # 或编辑.env文件
   ```

3. 运行实时聊天
   ```bash
   python real_time_chat.py
   ```

四、其他运行方式
---------------
1. 交互式演示
   ```bash
   python interactive_demo.py
   ```

2. 直接对话测试
   ```bash
   python direct_dialogue.py
   ```

3. 自动化对话
   ```bash
   python auto_dialogue.py
   ```

五、常见问题
-----------
1. 缺少API密钥？
   - 访问 https://platform.deepseek.com/ 注册获取
   - 填入.env文件的DEEPSEEK_API_KEY字段

2. 不想安装Poetry？
   - 手动安装pyproject.toml中的依赖
   - 或只用聊天功能: pip install aiohttp python-dotenv

3. 不想运行Redis？
   - demo_main.py使用模拟组件，可不依赖Redis运行
   - 完整系统任务调度需要Redis

六、项目结构
-----------
- opencareer/agents/    - 4个智能体 (Brain, Work, Emotion, Log)
- opencareer/skills/    - 核心技能 (学习计划、模拟面试、情感支持)
- opencareer/mcp/       - MCP服务器 (技能执行管理)
- opencareer/memory/    - 混合记忆系统 (向量+结构化)

七、测试验证
-----------
```bash
poetry run pytest          # 运行测试套件
python check_imports.py    # 检查导入
```
