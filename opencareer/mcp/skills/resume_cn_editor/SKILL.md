# resume_cn_editor

## Description
中文简历生成与优化。当用户提到写简历、改简历、简历制作、求职简历、简历优化、ATS 检查、简历导出 PDF 时使用。

## Triggers
- 写简历
- 改简历
- 简历制作
- 求职简历
- 简历优化
- 简历生成
- ATS 检查
- 导出简历
- 简历 PDF
- 简历制作

## Tool
resume_skill

## Instructions
当用户触发此 skill 时，按以下步骤执行：

### Step 1: 读取记忆
从 career_memory.json 中查找已有的简历相关信息（教育背景、目标岗位、求职类型、技能、经历等）。

### Step 2: 信息补全
对比以下必填字段，如有缺失则向用户逐一提问：
- 姓名
- 目标岗位
- 求职类型（校招/社招/资深/转行/双语）
- 教育背景（学校/专业/学历）
- 核心经历或项目

### Step 3: 简历生成
信息齐全后，按分流逻辑生成可投递版本（校招、社招初级、社招中高级、资深/管理岗、转行、中英双语）。

技能清单必须为每项技能标注熟练程度，统一使用以下三级：
- 熟练：有完整项目/工作证据，能说明使用场景、具体行动和结果
- 掌握：有实际使用经历，但证据完整度或独立承担程度不足
- 了解：仅提到学习、接触或工具名称，尚无充分实践证据

技能条目使用“技能名称（熟练程度）”格式，例如“Java（熟练）”。不得仅凭用户提到过某项技能就写“熟练”，不得使用“精通”，除非用户提供了多段独立、可验证的高级实践证据。

### Step 4: 质量评估
按自检清单评分并修正。

### Step 5: ATS 优化
调整关键词和格式。

### Step 6: PDF 导出
生成可投递 PDF。

## Requirements
- 不编造经历、学历、证书与指标
- 不编造技能熟练度；熟练度必须与技能证据链一致
- 主版本必须为中文
- 版式保持 ATS 友好：单栏、标准标题、可复制文本
