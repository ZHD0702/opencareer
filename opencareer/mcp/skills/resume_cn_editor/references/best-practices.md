# 中文简历写作最佳实践

本指南用于生成可投递的中文简历，强调真实性、岗位匹配和结果导向。

## 四条硬规则

1. 不编造经历
- 不虚构公司、岗位、项目、学历、证书、指标。
- 无法证明的数据宁可不写，也不要杜撰。

2. 优先量化成果
- 能写数字就写数字，优先写“提升/下降/节省/覆盖/规模”。
- 推荐表达：提升 32%、节省 15 万成本、日活 20 万、服务 3000+ 客户。

3. 经历统一写法
- 每条经历按“动作 + 方法 + 结果”。
- 示例：主导支付链路改造，通过分层缓存和异步重试，将超时率从 1.8% 降至 0.4%。

4. 优先岗位匹配
- 每次投递都按 JD 重排内容，把最匹配的经历放前面。
- 不相关内容降权或删除，保证简历主题清晰。

## 内容组织原则

1. 校招：教育、项目、实习优先。
2. 社招：工作经历和业务结果优先。
3. 资深/管理岗：团队与组织影响优先。
4. 转行：可迁移能力 + 新方向证据优先。

## 各模块写法

### 个人摘要

- 2-4 句，包含年限、方向、关键优势、代表成果。
- 不写空话：避免“责任心强、学习能力强”这类不可验证表述。

### 工作/实习经历

- 每段 3-5 条要点，最近经历可写到 5 条。
- 每条最多 1-2 行，避免大段叙述。
- 动词开头：主导、设计、搭建、优化、推进、落地、治理、提升。

### 项目经历

- 写清角色、目标、关键动作、结果指标。
- 重点展示复杂问题处理和业务价值。

### 技能清单

- 分类展示：语言、框架、中间件、数据库、工程化工具。
- 只写可被面试验证的技能。

## 页数与密度建议

1. 校招/初级：1 页优先。
2. 中高级：1-2 页。
3. 资深/管理岗：2 页内。

## 常见问题

1. 只写职责，不写结果。
2. 指标口径不清，前后矛盾。
3. 同一岗位投所有职位，缺少定制。
4. 技能堆砌过多，经历里无法印证。
5. 模板花哨，影响 ATS 解析。

## 快速自检

1. 是否存在任何虚构信息。
2. 是否每段都有“动作 + 方法 + 结果”。
3. 是否至少 60% 要点有量化数据。
4. 是否前半页已经体现岗位匹配。
5. 是否删掉与目标岗位无关的信息。
