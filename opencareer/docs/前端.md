# AI Career Companion — 前端设计文档

## 概述

基于 React + Vite + TypeScript + Tailwind CSS v4 的 Web GUI 前端，与 FastAPI 后端 (port 8080) 配合使用。本文档记录前端页面设计的所有决策。

---

### 1.2 主题切换

- **默认行为**: 跟随系统 `prefers-color-scheme`
- **手动覆盖**: 提供切换按钮，用户可手动选择 亮色/暗色/跟随系统
- **存储方式**: localStorage 记录用户偏好
- **实现**: Tailwind `dark:` 前缀 + 手动 toggle class 策略

### 1.3 视觉密度：舒适宽松

- 圆角: 大圆角为主 (`rounded-xl`, `rounded-2xl`)
- 间距: 内容区 padding 增大 (p-5 → p-6, gap 增大)
- 字号: 正文不小于 `text-sm`，侧栏最小 `text-xs`
- 行高: 对话内容使用 `leading-relaxed`

### 1.4 字体

- 默认使用系统字体栈: `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`
- 中文字体依赖系统默认 (Windows: 微软雅黑, macOS: 苹方)
- 暂不引入 Web 字体（性能考虑）

## 2. 整体布局与导航

### 2.1 页面结构：单页应用

所有功能在一个页面上，不引入路由。侧栏切换面板，主区域始终是对话。

### 2.2 顶部 Header

全局顶栏，高度约 48-56px，横跨全宽：

```
┌──────────────────────────────────────────────────┐
│  AI Career Companion        🌙 主题切换  ⚙ 设置  │ ← Header
├──────────────┬──────────────────────────────────┤
│   Sidebar    │         Chat Area                 │
└──────────────┴──────────────────────────────────┘
```

| 区域 | 内容 |
|------|------|
| 左侧 | 应用 Logo/名称 "AI Career Companion" |
| 右侧 | 主题切换按钮 (亮色/暗色/跟随系统)、设置入口 (预留) |

Header 职责：
- 展示应用品牌标识
- 提供全局操作入口（主题切换、设置）
- 从 Sidebar 中移出标题，避免折叠时丢失品牌识别

### 2.3 可折叠侧栏

侧栏支持展开/折叠切换：

- **展开模式** (280px)：完整显示 Tab 导航 + 面板内容
- **折叠模式** (48px)：仅显示 Tab 图标，悬浮时弹出面板
- **切换按钮**：位于 Header 左侧或侧栏顶部，使用汉堡/箭头图标
- **状态记忆**：折叠状态记录在 localStorage

```
展开:                                  折叠:
┌──────────────────┬───────────┐    ┌──┬──────────────────────────┐
│  AI Career       │           │    │💟│  Chat Area                │
│  Companion       │  Chat     │    │📄│                          │
│  ┌─情绪──简历──┐ │           │    │  │                          │
│  │ 内容区      │ │           │    │  │                          │
│  │            │ │           │    │  │                          │
└──────────────────┴───────────┘    └──┴──────────────────────────┘
```

### 2.4 布局结构树

```
App
└── Layout
    ├── Header (全局顶栏)
    │   ├── SidebarToggle (侧栏折叠按钮)
    │   ├── AppTitle (应用名称)
    │   └── HeaderActions (主题切换、设置)
    └── Body (flex-1, flex)
        ├── Sidebar (可折叠, 280px/48px)
        │   ├── TabNav (情绪/简历切换)
        │   └── TabContent (EmotionTab/ResumeTab)
        └── ChatArea (flex-1)
            ├── MessageList
            └── ChatInput
```

## 3. 对话区域设计

### 3.1 欢迎页（空消息状态）

当尚无对话消息时，显示：

```
        🧡 AI Career Companion
        你的职业发展助手

   ┌─────────────────────────┐
   │  💡 怎么优化我的简历？     │
   │  💡 面试前应该准备什么？   │
   │  💡 如何谈薪资？         │
   │  💡 没有实习经历怎么办？   │
   │  💡 如何规划职业发展路径？  │
   └─────────────────────────┘
```

- 建议问题为可点击按钮，点击后自动发送该消息
- 问题列表可从后端配置或静态预设

### 3.2 消息气泡

每条消息包含：

| 元素 | 说明 |
|------|------|
| 头像 | 用户/AI 角色圆形图标，位于气泡一侧 |
| 时间戳 | 消息发送时间，格式 `HH:mm`，显示在气泡旁 |
| 内容 | 支持 Markdown 渲染（加粗、列表、代码块等） |
| 流式光标 | AI 回复进行中时，闪烁光标指示 |

**气泡样式**（暖色方案下的体现）：

| 角色 | 背景色 | 文字色 | 对齐 |
|------|--------|--------|------|
| 用户 | 珊瑚橙 `#ea580c` (light) / `#fdba74` (dark) | 白色 (light) / 深棕 (dark) | 靠右 |
| AI | 米色 `#ffedd5` (light) / `#2d2520` (dark) | 深棕 (light) / 浅杏 (dark) | 靠左 |

### 3.3 消息操作

每条 AI 消息下方提供：

- **复制按钮** (Copy)：点击复制消息全文到剪贴板，复制后显示 ✓ 反馈
- **重新生成** (Regenerate)：对当前回复不满意时，重新触发 AI 生成
- **点赞/踩** (👍👎)：收集回复质量反馈，点击后高亮选中项

### 3.4 输入区域

```
┌──────────────────────────────────────────────┐
│  💬 帮我看简历  📝 模拟面试  💰 薪资谈判      │  ← 快捷建议
│  ┌──────────────────────────────────────────┐│
│  │ 输入你的问题...                    (多行)  ││  ← 多行输入框
│  │                                          ││
│  └──────────────────────────────────────────┘│
│  🔵 情绪正在分析中...              [发送 ⬆]  │  ← 状态 + 发送
└──────────────────────────────────────────────┘
```

- **多行输入框**: 自动增高，Shift+Enter 换行，Enter 发送
- **快捷建议**: 可点击的建议标签，点击填入输入框（不直接发送）
- **处理状态**: 显示当前 Agent 处理阶段（如"情绪分析中..."、"简历提取中..."）
- **Markdown 支持**: 输入框内支持 Markdown 语法，AI 回复中渲染 Markdown

## 4. 侧边栏设计

### 4.1 Tab 列表（共 5 个）

| Tab | 图标 | 功能 |
|-----|------|------|
| 情绪 | Heart | 当前心情 + 趋势柱状图 + 预警 + 历史记录 + 周期报告 |
| 简历 | FileText | 简历预览 + 折叠编辑 + 文件上传 |
| 求职进度 | BarChart | 投递/面试/offer 状态看板 |
| 技能评估 | Sparkles | 技能雷达图 / 匹配度分析 |
| 历史会话 | Clock | 过往对话列表，可切换查看 |

**折叠模式 (48px)**：仅显示 5 个图标竖排排列，悬浮时弹出完整面板。

**展开模式 (280px)**：水平 Tab 导航切换（如当前 2 个 Tab 改为 5 个可能需要改为垂直列表或紧凑水平布局）。

### 4.2 情绪面板增强

保留当前结构，新增：

- **周期情绪报告**: 周/月度情绪总结卡片，包含趋势变化、主要情绪分布、关怀建议
- 位于当前「近期情绪记录」列表上方或下方

### 4.3 简历面板增强

保留当前 5 个折叠编辑区域，新增：

- **简历预览模式**: 将所有字段渲染为一份完整简历效果（类似 A4 纸卡片），默认显示预览，点击编辑进入编辑模式
- **简历文件上传**: 支持拖拽/点击上传 PDF 或 Docx 文件，后端解析后自动填充 profile 字段
- **AI 优化建议**: 根据对话中提取的顾虑和技能，自动给出简历改进建议（预留）

### 4.4 求职进度看板（新增）

- 展示投递数量、面试次数、offer 状态等
- 对话中自动提取进度信息
- 支持手动编辑

### 4.5 技能评估面板（新增）

- 雷达图/条形图展示技能匹配度
- 根据目标岗位分析技能差距
- 给出技能提升建议

### 4.6 历史会话面板（新增）

- 会话列表，显示时间 + 标题/摘要
- 点击切换查看历史对话
- 支持删除历史会话

## 5. 动画与过渡

**整体风格**: 活泼丰富 — 注重交互的温度和趣味，大量使用 spring 动画和微交互反馈。

**动画方案**: Framer Motion — 全部动画基于 framer-motion 实现，利用其 spring 物理引擎、layout animations、stagger 编排等能力。

### 5.1 侧栏动效

#### 折叠/展开

| 场景 | 动效 | 参数 |
|------|------|------|
| 展开 (48→280px) | spring 弹性宽度变化 + 内容淡入 | `type: "spring"`, `stiffness: 300`, `damping: 30`, 轻微 `overshoot` |
| 折叠 (280→48px) | spring 弹性宽度变化 + 内容淡出 | 同上，方向相反 |

- **实现要点**: 使用 `AnimatePresence` 包裹侧栏内容区域，文字和 Tab 标签在折叠时淡出，展开时带 stagger 延迟回来
- **性能**: 不使用 `width` 过渡（触发重排），改用 `layout` animation 或 `transform` 方式

#### 悬浮弹出面板（48px 折叠模式）

| 场景 | 动效 | 参数 |
|------|------|------|
| 弹出面板 | 从侧边滑入 + 淡入 | `initial: { x: -16, opacity: 0 }`, `animate: { x: 0, opacity: 1 }`, `duration: 0.25` |
| 关闭面板 | 反向滑出 + 淡出 | 同上方向相反 |

- 面板内容从图标位置滑出，层级感强
- 鼠标移出面板区域后延迟 200ms 关闭，防止误触

### 5.2 Tab 切换

| 场景 | 动效 | 参数 |
|------|------|------|
| 面板内容切换 | 淡入淡出 | `AnimatePresence` 模式切换，`opacity 0→1`, `duration: 0.2` |

- 切换时旧内容直接替换，不做滑动（避免侧栏内横向滑动过于拥挤）

### 5.3 消息动效

#### 消息气泡入场

| 场景 | 动效 | 参数 |
|------|------|------|
| 新消息出现 | 仅淡入 | `opacity 0→1`, `duration: 0.2` |

- 不做位移动画，避免对话流中产生不稳定感
- 消息列表使用 `AnimatePresence` 追踪新增消息

#### 流式回复光标

| 场景 | 动效 | 参数 |
|------|------|------|
| AI 回复进行中 | 呼吸光点 | 珊瑚橙色圆点 `●`，`scale 0.8 → 1.2 → 0.8` 呼吸循环，`duration: 1.2s`, `repeat: Infinity` |
| 回复完成 | 光点消失 | 光点淡出 `opacity 1→0`, `duration: 0.3`，同时消息气泡完成定格 |

- 光点位于 AI 消息末尾
- 光点颜色使用珊瑚橙 `#ea580c` (light) / `#fdba74` (dark)，与主色呼应

### 5.4 交互反馈

#### 按钮/可点击元素

| 场景 | 动效 | 参数 |
|------|------|------|
| Hover | 轻微放大 + 背景色过渡 | `scale: 1.03`, `duration: 0.2`, `ease: ease-out` |
| Click (按下) | 缩回 | `scale: 0.97`, `duration: 0.1` |
| Click (释放) | 弹回正常 | `scale: 1.0`, `type: "spring"`, `stiffness: 400` |

- 适用于：建议问题按钮、发送按钮、侧栏 Tab、可折叠区域标题
- Framer Motion 的 `whileHover` 和 `whileTap` 实现

#### 点赞/踩反馈

| 场景 | 动效 | 参数 |
|------|------|------|
| 点击选中 | 弹跳 + 填充主题色 | `scale: 1 → 1.3 → 1`, `type: "spring"`, `stiffness: 400`, `damping: 10` |
| 取消选中 | 缩回 + 颜色还原 | `scale: 1 → 0.8 → 1`, 颜色过渡回默认 |
| 切换选中 | 旧图标缩回 + 新图标弹跳 | 两个动画顺序执行，间隔 50ms |

#### 复制按钮

| 场景 | 动效 | 参数 |
|------|------|------|
| 点击后 | 图标切换 + 弹跳 | 复制图标 → ✓ 勾图标，弹跳 `scale 1→1.2→1`, `duration: 0.4` |
| 恢复 | 2s 后图标还原为复制 | 勾 → 复制图标的淡入淡出 |

### 5.5 欢迎页入场

| 场景 | 动效 | 参数 |
|------|------|------|
| Logo/标题 | 从上方轻微滑入 | `initial: { y: -20, opacity: 0 }`, `animate: { y: 0, opacity: 1 }`, `duration: 0.5` |
| 建议问题卡片 | 依次从下方淡入升起 | `initial: { y: 12, opacity: 0 }`, stagger 延迟 `0.08s/个`, spring |
| 副标题 | 跟随 Logo 延迟 100ms 淡入 | `delay: 0.1`, `duration: 0.4` |

- 使用 Framer Motion 的 `staggerChildren` 编排卡片依次出现
- 仅在首次加载或清空会话后展示，切换会话不重复播放

### 5.6 自动滚动

| 场景 | 行为 | 参数 |
|------|------|------|
| 新消息到达 | 平滑滚动到底部 | `behavior: "smooth"`, 使用 `scrollIntoView` 或 framer-motion `useScroll` |
| AI 流式输出中 | 跟随内容增长持续滚动 | 底部始终可见，光点始终在视口内 |
| 用户在历史消息中 | 不强制滚动 | 检测用户是否在底部附近（100px 阈值），若在则自动滚，否则不滚 |

### 5.7 输入框动效

| 场景 | 动效 | 参数 |
|------|------|------|
| 聚焦 | 光晕扩散 + 轻微放大 | 边框 `box-shadow` 扩散为珊瑚橙光晕 + `scale: 1.01`, `duration: 0.3` |
| 失焦 | 光晕消失 + 恢复大小 | 反向过渡，`duration: 0.2` |
| 发送中 | 输入框略微缩小 + 降低透明度 | `scale: 0.99`, `opacity: 0.7`，表示不可输入 |
| 快捷建议点击 | 标签弹跳 + 填入输入框 | 点击的标签 `scale 1→1.15→1`，然后动画过渡到输入框内容 |

### 5.8 全局过渡

| 场景 | 动效 | 参数 |
|------|------|------|
| 主题切换 (light/dark) | 全页颜色过渡 | `transition: background-color 0.3s, color 0.3s, border-color 0.3s` |
| Toast/通知 | 从右上角滑入 | `initial: { x: 32, opacity: 0 }`, `animate: { x: 0, opacity: 1 }` |
| 加载状态 | 骨架屏脉冲 | 浅色脉冲动画，`opacity 0.5↔1`, `duration: 1.5s` |
