项目名称：OpenCareer（多智能体架构的求职助手）
项目概述：设计一个多智能体架构的求职项目，以朋友式的对话智能体为核心，为求职者提供全方位的求职支持。

目标用户：
- 应届毕业生：即将毕业或刚毕业的学生，缺乏工作经验
- 职场转行者：希望转换行业或职业方向的在职人士
- 在职跳槽者：已有工作经验，寻求更好机会的求职者

对话智能体性格：鼓励支持型与幽默朋友型结合，在提供专业建议的同时，以朋友般的语气鼓励用户，缓解求职压力。通过Prompt工程实现对话风格。

核心功能：
1. 帮助求职者提升自我技能
   - 输入：求职意向（行业、职位等）
   - 输出：具体的技能提升建议、个性化学习计划
   - 过程：根据求职意向分析所需技能缺口，推荐学习资源，设计学习计划（包括每日/每周任务、里程碑）
   - 督促机制：定时任务调度器定期提醒用户学习进度，鼓励完成计划

2. 帮助求职者匹配实时岗位（*暂时不用实现，留出代码空间）
   - 输入：用户的学历、专业、工作经验、技能等信息
   - 输出：匹配的最优岗位列表
   - 过程：接入招聘网站API，根据用户画像进行实时岗位匹配

3. 对话中提炼并记录求职信息
   - 提炼字段：教育背景、工作经验、技能列表、项目经历
   - 过程：在与用户的自然对话中自动识别并结构化存储上述信息
   - 触发时机：每N轮对话后、用户信息更新时、上下文快满时

4. 简历撰写与优化（*暂时不用实现，留出代码空间）
   - 输入：用户提供的原始简历或从对话中提炼的信息
   - 输出：优化后的简历（ATS友好、突出亮点）
   - 过程：根据目标职位描述调整简历内容，优化排版和关键词

5. 简历投递（*暂时不用实现，留出代码空间）
   - 过程：在沙箱环境中打开浏览器，用户在确认后自动在指定招聘网站投递简历
   - 注意：需用户明确授权，并遵守网站条款

6. 模拟面试
   - 形式：文本对话
   - 过程：针对用户的目标职位进行模拟面试问答，提供反馈和改进建议
   - 评估：根据回答内容给出评分和优化建议

7. 情感陪伴
   - 触发机制：关键词检测（压力、焦虑、开心等）、情感分析模型、用户主动触发
   - 范围：在用户求职压力大、情绪低落时提供情绪支持
   - 边界：仅提供鼓励和陪伴，不涉及专业心理咨询

系统架构约束：
- 技术栈：LangChain + MCP (Model Context Protocol) + SKILLs架构
- 智能体架构：4个智能体（大脑、工作代理、情感代理、日志代理）
- 功能实现：除最底层对话系统和记忆系统外，所有功能必须通过SKILL实现
- 调度逻辑：大脑（DeepSeek小模型）负责调度其他智能体，根据用户需求调用相应代理
- 记忆系统：存储用户个人信息、对话历史、提炼的关键信息、学习计划进度，分文件保存
- 项目结构：按功能模块组织，兼容SKILLs的模块化规范

非功能需求：
- 隐私安全：用户个人信息、简历等数据需加密存储，未经用户同意不得共享给第三方（注：加密存储为后期实现要求，前期开发阶段暂不实现）
- 对话记忆：智能体需记住用户上下文，提供连贯的对话体验
- 多智能体协作：架构设计需支持多个智能体协同工作
- 可测试性：支持单元测试、集成测试、端到端测试
- 可扩展性：SKILLs模块化设计，便于新增功能

未来扩展：
- 实时岗位匹配
- 简历撰写与优化
- 自动化简历投递
- 更多技能来源（skillhub等平台）集成
