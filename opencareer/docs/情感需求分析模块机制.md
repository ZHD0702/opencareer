# 情感需求分析模块机制

## 概述

OpenCareer 的情感需求分析模块负责在入口处分析用户输入中的情绪状态，并根据情绪严重程度决定是否将对话路由到情感支持（EmotionAgent）还是继续执行工作需求（WorkAgent）。系统采用**三层防护**机制确保用户情绪被优先关注。

---

## 架构总览

```
User Input
    │
    ▼
BrainAgent._analyze_demand()
    │
    ├─ LLM 路径 (emotion_analysis.yaml)
    │   └─ 输出结构化 JSON → emotions[], overall_state, support_intensity, suggested_action
    │
    └─ 备用路径 (_simulate_demand_analysis)
        └─ 关键词匹配 → demand_type: job_related / emotional / mixed / unknown
    │
    ▼
_determine_target_agent()
    │
    ├─ emotion_agent (情绪优先)
    └─ work_agent (工作需求)
            │
            ▼
    WorkAgent 二次检查
        ├─ support_intensity 检查 → handoff
        └─ 关键词情绪检测 → handoff
```

---

## 第1层：BrainAgent 需求分析

### 主路径：LLM 分析 (`emotion_analysis.yaml`)

使用大模型对用户输入进行深度情感分析，输出结构化 JSON：

```json
{
  "emotions": [
    { "label": "焦虑", "confidence": 0.8 }
  ],
  "overall_state": "negative | positive | neutral | crisis",
  "suggested_action": "work | emotional_support",
  "support_intensity": "none | low | medium | high | crisis",
  "analysis": {
    "keywords_detected": ["压力大", "简历"],
    "tone_patterns": ["fragmented sentences"],
    "question_type": "emotional_venting",
    "trend": "declining | stable | improving | fluctuating",
    "attention_focused": true | false,
    "reasoning": "简要说明"
  }
}
```

**support_intensity 五档定义：**
| 等级 | 含义 | 行为 |
|------|------|------|
| none | 无需支持 | 正常处理工作需求 |
| low | 轻度鼓励 | 正常处理，语气温和 |
| medium | 明显困扰 | 先认可情绪，再处理需求 |
| high | 显著困扰 | 优先情绪支持 |
| crisis | 极度痛苦 | 强制情感支持，停止所有工作 |

**关键词检测维度（prompt 内置）：**
- 负面关键词：好难、不想活了、压力大、焦虑、烦、累了、受不了、没希望、放弃、不想干
- 求助信号：帮帮我、怎么办、有没有办法、能聊聊吗
- 自我怀疑：是不是我太菜、我不行、没能力、比别人差
- 语气线索：唉、哎、算了、碎片化句子、重复提问

### 备用路径：关键词匹配 (`_simulate_demand_analysis`)

当 LLM 不可用时使用，基于关键词计数分类。

**工作类关键词（job_keywords）：**
`python, skill, learn, study, interview, job, career, resume, position, apply, application, technical, 简历, 面试, 求职, 工作, 学习, 技能, 技术, 招聘, 跳槽, 投递, 职位, 实习, 校招, 社招, offer, 找工作`

**情绪类关键词（emotion_keywords）：**
`stress, stressed, anxious, anxiety, nervous, worried, happy, excited, discouraged, frustrated, tired, overwhelmed, 焦虑, 压力, 紧张, 沮丧, 难过, 迷茫, 烦躁, 崩溃, 失眠, 害怕, 担心, 不安, 痛苦, 抑郁, 急躁, 绝望, 心累`

**决策逻辑：**
| 条件 | demand_type |
|------|------------|
| 同时命中工作 + 情绪关键词 | mixed |
| 仅命中工作关键词 | job_related |
| 仅命中情绪关键词 | emotional |
| 无命中 | unknown |
| 置信度 < 0.3 | 不路由，先澄清 |

### 标准化处理 (`_normalize_emotion_analysis`)

将 LLM 的 emotion-analysis 格式转换为统一的 `demand_analysis` 格式：

```
derived demand_type = 
  overall_state == "crisis"      → "emotional"
  suggested_action == "emotional_support" → "emotional"
  suggested_action == "work"     → "job_related"
  
mixed 检测：emotional + 关键词含工作指示词 → "mixed"
工作指示词：简历, 面试, 求职, 工作, offer, 跳槽, 投递, 招聘, resume, interview, job, career
```

## 第2层：目标 Agent 路由 (`_determine_target_agent`)

严格按优先级决策：

| 优先级 | 条件 | 路由到 |
|--------|------|--------|
| 1 | overall_state == "crisis" | emotion_agent |
| 2 | support_intensity == "high" 或 "crisis" | emotion_agent |
| 3 | suggested_action == "emotional_support" | emotion_agent |
| 4 | demand_type == "job_related" | work_agent |
| 5 | demand_type == "mixed" 或 "emotional" | emotion_agent |
| 6 | 置信度 < 0.3 或类型 == "unknown" | None（先澄清） |

关键设计：**mixed 类型优先路由到 emotion_agent**，确保情绪问题不被工作需求淹没。

---

## 第3层：WorkAgent 二次检查

即使 BrainAgent 判断可以路由到 WorkAgent，WorkAgent 仍会独立进行双重确认：

### 检查 1：support_intensity 从 BrainAgent 继承

```python
demand_analysis = context.get("demand_analysis", {})
support_intensity = demand_analysis.get("support_intensity", "")
if support_intensity in ("high", "crisis"):
    → 立即转 emotion_agent
```

### 检查 2：中文关键词情绪检测

独立的关键词检测方法 `_detect_emotional_distress()`（取自 `career_advice.yaml`），包含中文关键词：

`沮丧, 焦虑, 压力, 难过, 紧张, 迷茫, 烦躁, 崩溃, 害怕, 担心, 不安, 绝望, 痛苦, 想放弃, 不想活了, 受不了, 没希望, 累了, 心累, 失眠, 帮帮我, 怎么办`

命中时 → 先给予情感支持回应，再建议转 emotion_agent。

### 语气校准

`_build_conversational_advice()` 根据 `support_intensity` 调整回复语气：

| support_intensity | 语气 | 行为 |
|-------------------|------|------|
| none/low | 正常 | 直接提供求职建议 |
| medium | 温和 | 先认可感受，再给建议 |
| high | 共情优先 | 显著放慢节奏，强调支持 |
| crisis | 只安抚 | 停止工作建议，纯情感支持 |

## 数据流总结

```
用户输入 "我最近找工作压力很大，简历投了几十份都没回音"
    │
    ▼
BrainAgent._analyze_demand()
    ├─ LLM 分析：emotions=[焦虑, 沮丧], overall_state=negative,
    │   suggested_action=emotional_support, support_intensity=medium
    │   → demand_type = emotional → 检查 keywords_detected=["压力大","简历"]
    │   → 含工作关键词 → demand_type = mixed
    │
    ▼
_determine_target_agent(): demand_type=mixed → emotion_agent
    │
    ▼
EmotionAgent 处理情绪需求（可后续建议转接 WorkAgent）
```

```
用户输入 "我想学习 Python 后端开发"
    │
    ▼
BrainAgent._analyze_demand()
    ├─ LLM 分析：emotions=[], overall_state=neutral,
    │   suggested_action=work, support_intensity=none
    │
    ▼
_determine_target_agent(): demand_type=job_related → work_agent
    │
    ▼
WorkAgent.process_user_request()
    ├─ support_intensity=none → 通过
    ├─ _detect_emotional_distress() → 无匹配
    └─ 正常执行工作需求
```
