## Slide 3 — 核心架构：四智能体协作

```
                        用户
                         │
                   ┌─────▼──────────┐
                   │   Brain Agent  │  ← 唯一入口，Judge-and-Handoff
                   │   大脑·调度中心  │    需求分析 → 情绪检测 → 路由决策
                   └──┬────────┬──┬─┘
                      │        │  │
             ┌────────▼──┐ ┌──▼──▼──┐ ┌──────────┐
             │Work Agent │ │Emotion │ │ Log Agent│
             │  求职代理  │ │  Agent │ │  日志代理 │
             │ SKILLs调用 │ │ 情感代理│ │  信息提取 │
             └─────┬─────┘ └───┬────┘ └────┬─────┘
                   │            │           │
                   └────────────┼───────────┘
                                ▼
              ┌─────────────────────────────┐
              │      ConversationContext     │
              │  对话历史 · 情绪追踪 · 用户画像 │
              └─────────────┬───────────────┘
                            ▼
              ┌─────────────────────────────┐
              │  记忆系统 (ChromaDB+SQLite)  │
              │     MCP Server + SKILLs      │
              └─────────────────────────────┘
```

**核心逻辑**: Brain 每轮重新判断用户需求 → 路由到最合适的 Agent → Agent 调用 SKILL 完成任务

**讲解**: "Brain 是调度中心，不直接回答用户，而是分析需求后分发给下游 Agent。关键是 Judge-and-Handoff 模式——每轮重新判断，而非死板状态机。"

**视觉**: 分层架构图，Brain 在上，三个 Agent 在中，记忆/SKILL 层在下

## Slide 4 — 核心功能①：情感陪伴（⭐最大亮点）

```
   三层情绪防护机制——AI 能感知你的情绪

   Layer 1: 逐轮检测 (Brain Agent)
   ┌──────────────────────────────────────────┐
   │ 每轮对话都分析情绪: 焦虑/沮丧/开心/...     │
   │ 输出: emotion_label + confidence + intensity │
   └──────────────────────────────────────────┘
                    ↓
   Layer 2: 5轮滑动窗口趋势分析
   ┌──────────────────────────────────────────┐
   │ 连续 ≥2 轮负面 → 触发情绪预警              │
   │ 趋势: improving / declining / stable       │
   └──────────────────────────────────────────┘
                    ↓
   Layer 3: 跨轮次积累 → 路由覆盖
   ┌──────────────────────────────────────────┐
   │ 负面占比 > 60% → 强制转到 Emotion Agent   │
   │ 即使用户在问求职问题，也优先安抚情绪        │
   └──────────────────────────────────────────┘

   Persona 设计: 鼓励支持型 + 幽默朋友型
   "你已经很棒了！求职路上每个人都会焦虑，这很正常~"
```

**讲解**: "这是我们的核心创新——AI 不只是识别你在说什么，还能感知你的情绪状态。当检测到连续负面情绪时，系统会强制先安抚再解决问题，就像一个细心的朋友。"

**视觉**: 三层漏斗/瀑布图，从宽到窄，强调层层过滤

## Slide 6 — 技术栈与亮点

```
  技术栈                              六大亮点

  AI模型    DeepSeek API               ⭐ 四智能体 Judge-and-Handoff
  后端      FastAPI + WebSocket         ⭐ 三层情绪防护 + 路由覆盖
  前端      React 19 + Tailwind v4      ⭐ 情感与功能深度融合
  记忆      ChromaDB + SQLite           ⭐ MCP + SKILLs 可插拔架构
  MCP       FastAPI Server              ⭐ 对话式被动信息提取
  调度      dramatiq + Redis            ⭐ 全链路流式实时推送
```

**讲解**: "全栈自研，从 Agent 框架到 MCP Server 均为自主实现。六大亮点中最核心的是情感与功能的融合——求职助手不应该是冰冷的工具。"

## 答辩问答准备

| 可能问题 | 回答方向 |
|---------|---------|
| 和 ChatGPT 有什么区别？ | ChatGPT 是通用对话，我们聚焦求职场景 + 情感感知 + 多智能体协作 |
| 为什么不用 GPT-4？ | DeepSeek 中文能力强、成本低、结构化 JSON 输出稳定 |
| 情感分析准确吗？ | LLM 语义 + 关键词 + 统计趋势 三重保障，宁保守不激进 |
| 智能体会冲突吗？ | Brain 单入口 + Judge-and-Handoff 模式，每轮只有一个 Agent 响应 |
| 信息提取会编造吗？ | 温度 0.1 + delta 增量 + 宁缺毋滥原则，不支持的内容输出空 |
| 能商用吗？ | 核心架构已验证，下一步完善测试、安全加密、容器化部署 |
