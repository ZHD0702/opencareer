# OpenCareer并发架构方案

## 1. 项目背景与目标

### 1.1 项目背景
OpenCareer是一个多智能体架构的求职助手，采用LangChain + MCP + SKILLs技术栈。系统包含4个核心智能体：大脑（调度智能体）、工作代理、情感代理、日志代理。

### 1.2 并发需求分析
- **并发规模**：低并发（同时服务几个用户）
- **响应要求**：可接受短暂延迟（几秒内响应）
- **扩展需求**：适度扩展，预留未来扩展接口
- **用户场景**：应届毕业生、职场转行者、在职跳槽者

### 1.3 设计目标
1. **响应性**：保证用户对话的流畅体验
2. **可靠性**：多智能体协作稳定可靠
3. **可扩展性**：支持未来功能扩展和并发提升
4. **隔离性**：不同用户、不同代理之间互不干扰

## 2. 整体架构设计

### 2.1 架构图
```
+----------------+     +----------------+     +----------------+
|   用户输入     | --> |     大脑       | --> |   智能体调度   |
| (多个会话)     |     | (中央调度器)   |     |   与协调       |
+----------------+     +----------------+     +----------------+
                                          |
                                          v
        +----------------+----------------+----------------+
        |                |                |                |
        v                v                v                v
+----------------+ +----------------+ +----------------+ +----------------+
|   工作代理     | |   情感代理     | |   日志代理     | |   其他代理     |
| (技能提升)     | | (情感支持)     | | (信息提取)     | | (未来扩展)     |
+----------------+ +----------------+ +----------------+ +----------------+
        |                |                |                |
        +----------------+----------------+----------------+
                                          |
                                          v
                                +----------------+
                                |   结果聚合器   |
                                |   与回复生成   |
                                +----------------+
```

### 2.2 核心原则
1. **大脑中心调度**：大脑作为中央调度器，负责路由所有用户请求
2. **异步非阻塞**：采用异步编程模型，避免阻塞等待
3. **会话隔离**：每个用户会话独立处理，数据不交叉
4. **资源池化**：智能体资源按需分配，避免浪费

```python
from concurrent.futures import ThreadPoolExecutor

class BrainScheduler:
```

#### 3.1.2 智能体调用机制
```python
# 伪代码：智能体异步调用
class AgentInvoker:
    def __init__(self):
        self.agent_pool = AgentPool()  # 代理池
        self.message_queue = asyncio.Queue()  # 消息队列

    async def call_agent(self, agent_type: str, session_id: str, input_data: dict) -> dict:
        """
        异步调用智能体
        """
        # 1. 从代理池获取代理实例
        agent = await self.agent_pool.acquire(agent_type)

        try:
            # 2. 异步执行代理任务
            result = await asyncio.to_thread(
                agent.process,
                session_id=session_id,
                input_data=input_data
            )
            return result
        finally:
            # 3. 释放代理回池
            await self.agent_pool.release(agent_type, agent)
```

### 3.2 会话管理与隔离

#### 3.2.1 会话管理器
```python
class SessionManager:
    def __init__(self):
        self.sessions = {}  # session_id -> SessionData
        self.lock = asyncio.Lock()

    async def create_session(self, user_id: str) -> str:
        """创建新会话"""
        session_id = self.generate_session_id()
        async with self.lock:
            self.sessions[session_id] = {
                "user_id": user_id,
                "created_at": time.time(),
                "context": {},
                "agent_states": {},
                "is_active": True
            }
        return session_id

    async def get_session_data(self, session_id: str) -> dict:
        """获取会话数据（线程安全）"""
        async with self.lock:
            return self.sessions.get(session_id, {}).copy()

    async def update_session_context(self, session_id: str, key: str, value: any):
        """更新会话上下文"""
        async with self.lock:
            if session_id in self.sessions:
                self.sessions[session_id]["context"][key] = value
```

#### 3.2.2 数据隔离策略
1. **会话级隔离**：每个会话有独立的上下文和状态
2. **代理级隔离**：每个代理实例有独立的工作空间
3. **文件级隔离**：不同用户的数据存储在独立文件/目录中
4. **内存隔离**：使用独立的数据结构存储会话状态

### 3.3 资源管理与池化

#### 3.3.1 代理池实现
```python
class AgentPool:
    def __init__(self):
        self.pools = {
            "work_agent": asyncio.Queue(),
            "emotion_agent": asyncio.Queue(),
            "log_agent": asyncio.Queue()
        }
        self.max_pool_size = 3  # 每个代理类型最大实例数
        self.active_count = defaultdict(int)

    async def acquire(self, agent_type: str) -> Agent:
        """
        从池中获取代理实例
        """
        # 如果池中有可用实例，直接获取
        if not self.pools[agent_type].empty():
            return await self.pools[agent_type].get()

        # 如果未达到最大实例数，创建新实例
        if self.active_count[agent_type] < self.max_pool_size:
            agent = await self.create_agent(agent_type)
            self.active_count[agent_type] += 1
            return agent

        # 等待可用实例
        return await self.pools[agent_type].get()

    async def release(self, agent_type: str, agent: Agent):
        """
        释放代理回池
        """
        await self.pools[agent_type].put(agent)
```

## 4. 性能保障机制

### 4.1 负载监控与限流
```python
class LoadBalancer:
    def __init__(self):
        self.request_count = 0
        self.request_timestamps = []
        self.max_rps = 20  # 最大每秒请求数

    async def check_rate_limit(self) -> bool:
        """检查速率限制"""
        current_time = time.time()
        # 清理1秒前的记录
        self.request_timestamps = [
            ts for ts in self.request_timestamps
            if current_time - ts < 1.0
        ]

        # 检查是否超过限制
        if len(self.request_timestamps) >= self.max_rps:
            return False

        self.request_timestamps.append(current_time)
        return True
```

### 4.2 超时与重试机制
```python
class TimeoutRetryHandler:
    def __init__(self):
        self.default_timeout = 30.0  # 默认超时时间（秒）
        self.max_retries = 2         # 最大重试次数

    async def execute_with_timeout(self, coro, timeout=None):
        """带超时的协程执行"""
        timeout = timeout or self.default_timeout
        for attempt in range(self.max_retries + 1):
            try:
                return await asyncio.wait_for(coro, timeout=timeout)
            except asyncio.TimeoutError:
                if attempt == self.max_retries:
                    raise
                logging.warning(f"Timeout, retrying... (attempt {attempt + 1})")
```

### 4.3 内存与资源监控
```python
class ResourceMonitor:
    def __init__(self):
        self.memory_threshold = 0.8  # 内存使用阈值（80%）
        self.cpu_threshold = 0.7     # CPU使用阈值（70%）

    async def check_resources(self) -> dict:
        """检查系统资源"""
        import psutil

        memory_usage = psutil.virtual_memory().percent / 100
        cpu_usage = psutil.cpu_percent(interval=1) / 100

        return {
            "memory_usage": memory_usage,
            "cpu_usage": cpu_usage,
            "memory_ok": memory_usage < self.memory_threshold,
            "cpu_ok": cpu_usage < self.cpu_threshold
        }
```

```python
class EventBus:
    def __init__(self):
        self.subscribers = defaultdict(list)

    def subscribe(self, event_type: str, callback):
        """订阅事件"""
        self.subscribers[event_type].append(callback)

    async def publish(self, event_type: str, data: dict):
        """发布事件"""
        for callback in self.subscribers.get(event_type, []):
            asyncio.create_task(callback(data))
```

## 9. 故障恢复与容错

### 9.1 故障检测
```python
class HealthChecker:
    async def check_agent_health(self, agent_type: str) -> bool:
        """检查代理健康状态"""
        try:
            agent = self.agent_pool.get_agent(agent_type)
            response = await agent.health_check(timeout=5)
            return response["status"] == "healthy"
        except Exception as e:
            logging.error(f"Agent {agent_type} health check failed: {e}")
            return False
```

### 9.2 容错策略
1. **代理故障**：自动重启故障代理
2. **大脑故障**：备用大脑实例接管
3. **数据不一致**：会话数据备份与恢复
4. **网络故障**：重试机制与降级策略
